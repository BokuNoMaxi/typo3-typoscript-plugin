# TYPO3 TypoScript & PageTS

PhpStorm plugin: autocomplete and quick documentation (Ctrl+Q / F1) for
TypoScript, PageTS and UserTS properties.

No paid marketplace dependency, no runtime network calls. Property names,
types and descriptions are extracted **at maintenance time** from the
official TYPO3 documentation sources and bundled as JSON:

- `src/main/resources/data/typoscript.json` — generated by `tools/update-docs.py`
  from [TYPO3-Documentation/TYPO3CMS-Reference-Typoscript](https://github.com/TYPO3-Documentation/TYPO3CMS-Reference-Typoscript)
  (the same reST sources docs.typo3.org renders).

## Scope (MVP)

- Recognizes files by name: `*.typoscript`, `*.tsconfig`, `setup.txt`, `constants.txt`.
- Completion offers property names for TypoScript ContentObjects/Functions/Conditions/TopLevelObjects/DataProcessing
  in `.typoscript`/`setup.txt`/`constants.txt`, and PageTS/UserTS properties in `*.tsconfig` files.
- Quick documentation popup on hover / Ctrl+Q for any recognized property name.

**Not included** (would need a real TypoScript language/lexer/parser, a bigger project):
syntax highlighting, error/lint checking, go-to-definition, refactoring. Files stay
plain text as far as PhpStorm is concerned; this plugin only adds completion + docs
on top via a filename heuristic.

## Refreshing the bundled docs

```bash
python3 tools/update-docs.py
```

Re-clones/pulls the reference repo into `tools/.sources/` (gitignored) and
regenerates `src/main/resources/data/typoscript.json`. Run this when TYPO3
ships a new reference version, then commit the regenerated JSON.

## Development

```bash
./gradlew runIde      # launch a sandbox PhpStorm with the plugin installed
./gradlew buildPlugin # build the distributable plugin zip under build/distributions
```

Targets PhpStorm via the IntelliJ Platform Gradle Plugin (see `build.gradle.kts`).
